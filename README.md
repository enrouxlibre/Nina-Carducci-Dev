# Nina Carducci — Photographe professionnelle

---

## 🇫🇷 Français

### Description

Ce projet est réalisé dans le cadre de la formation **Développeur Web** sur [OpenClassrooms](https://openclassrooms.com).

Il s'agit d'optimiser le site web de **Nina Carducci**, photographe professionnelle basée à Bordeaux. Les objectifs principaux du projet sont :

- **Optimisation des performances** : compression et conversion des images, réduction du poids des fichiers
- **Amélioration du référencement (SEO)** : balises méta, données structurées Schema.org, balises Open Graph
- **Accessibilité** : mise en conformité avec les bonnes pratiques WCAG (contrastes, attributs ARIA, navigation clavier)
- **Débogage** : correction des bugs présents sur la galerie photos et le formulaire de contact

### Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5
- maugallery.js

### Structure du projet

```
index.html          — Page principale du site
assets/
  style.css         — Feuille de styles
  scripts.js        — Scripts JavaScript
  bootstrap/        — Framework CSS Bootstrap
  images/           — Images optimisées (320, 640, 1024, 1600 px)
rapport/            — Rapport d'optimisation et d'accessibilité
```

### Lancer le projet

Ouvrir `index.html` directement dans un navigateur, ou utiliser une extension de serveur local comme **Live Server** dans VS Code.

## 🇬🇧 English

### Description

This project is part of the **Web Developer** training program on [OpenClassrooms](https://openclassrooms.com).

The goal is to optimize the website of **Nina Carducci**, a professional photographer based in Bordeaux, France. The main objectives are:

- **Performance optimization**: image compression and conversion, file size reduction
- **SEO improvements**: meta tags, Schema.org structured data, Open Graph tags
- **Accessibility**: compliance with WCAG best practices (contrast ratios, ARIA attributes, keyboard navigation)
- **Debugging**: fixing bugs in the photo gallery and contact form

### Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5
- maugallery.js

### Project Structure

```
index.html          — Main page
assets/
  style.css         — Stylesheet
  scripts.js        — JavaScript scripts
  bootstrap/        — Bootstrap CSS framework
  images/           — Optimized images (320, 640, 1024, 1600 px)
rapport/            — Optimization and accessibility report
```

### Running the Project

Open `index.html` directly in a browser, or use a local server extension such as **Live Server** in VS Code.
